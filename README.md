# 🎓 Student Application Simulation Web App

A production-ready, frontend-only React application simulating an admissions portal. Features modern UI, strict validation, mock backend simulation, and local data persistence.

## Features
- **Comprehensive Form**: Captures personal, educational, and academic details with file upload simulation
- **Real-time Validation**: Required fields, email/phone regex, 500-char textarea limit, inline error feedback
- **Simulation Engine**: 2s network delay, 75% success rate, mock API behavior
- **Local Persistence**: Saves successful applications to `localStorage`
- **Responsive EdTech UI**: Clean, accessible, mobile-first Tailwind design
- **Zero External Dependencies**: Pure React + Tailwind for fast setup
